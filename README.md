## Vnts-Install-Shell For CentOS/Debian/Ubuntu/Fedora (32bit/64bit)

### Install（安装）

#### Gitee
```Bash
# 一键安装命令
wget https://raw.githubusercontent.com/Architect111/vnts-install/main/install-vnts.sh -O install-vnts.sh && chmod +x install-vnts.sh && ./install-vnts.sh install
```
#### Github
```Bash
# 一键安装命令
wget https://raw.githubusercontent.com/Architect111/vnts-install/main/install-vnts.sh -O install-vnts.sh && chmod +x install-vnts.sh && ./install-vnts.sh install
```
### New inatall
```Bash
./install-vnts.sh install
```
### Uninstall（卸载）
```Bash
./install-vnts.sh uninstall
```
### Update（更新）
```Bash
./install-vnts.sh update
```
### Server management（服务管理器）
```Bash
Usage: ./install-vnts.sh {install|update|uninstall|config|version}
```
